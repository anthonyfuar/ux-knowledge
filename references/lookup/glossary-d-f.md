# Glossary D-F

Usability + humane-design terms, D to F. Open when term needs exact meaning or finding/rationale needs exact wording.

## Terms
|Term|Meaning|See|
|---|---|---|
|Dark patterns / deceptive patterns|Interface tricks making people buy, share, subscribe or stay w/o meaning to; term dark patterns from 2010|../ethics/deceptive-patterns.md (named patterns, each w/ honest alternative)|
|Decision fatigue|Willingness to choose + choice quality both decline over repeated decisions. Paired w/ choice tax: every added option costs attention. Accumulated decisions degrade judgment + push toward defaults. Also filed as Choice tax / decision fatigue in A-C|../evidence/decision-fatigue-and-choice.md|
|Decision paralysis|Too many options overload working memory + choice stalls. Other outcome of option overload = hasty choice later regretted (buyer's remorse)|../laws/choice-overload.md|
|Decoy effect|Adding option clearly worse than target option shifts preference toward target|—|
|Default effect|Preselected option becomes outcome for most people, via inertia, loss aversion + status quo bias|../patterns/defaults-and-choice-architecture.md|
|Design critique|Peer review in repeated rounds; weak/unclear design parts surface once designers must justify every choice|../methods/design-critique.md|
|Digital well-being|Health of person's relationship w/ technology: time, attention, autonomy + habits|[Principles index](../principles/index.md)|
|Discount usability engineering|Movement for improving interfaces quickly + cheaply|—|
|Distinction bias|Side-by-side evaluation magnifies differences barely mattering when each experienced alone; documented 2004|—|
|Diversity, inclusion, equity|3 distinct things. Diversity = mix of people doing work + among decision-makers. Inclusion = their experience's quality, incl. whether they get to lead. Equity = processes + systems set up so diversity + inclusion outlast single project|—|
|Doherty Threshold|When system + user exchange responses in under 400 ms, productivity rises sharply|../laws/doherty-threshold.md|
|Dual-process theory (System 1 / System 2)|Fast, automatic intuition vs slow, effortful deliberation|../laws/cognitive-bias.md|
|Duration neglect|Episode length barely affects how it gets remembered; shown 1993; part of extension-neglect bias family|../laws/peak-end-rule.md|
|Early selection (Filter Theory)|Input passes bottleneck screening it on physical features; only then meaning analyzed|../laws/selective-attention.md|
|Edge case (contextual)|Behavior deviation, distinct from technical failure; where harm concentrates. Hypothetical: fitness app's shared-route feature lets ex-partner learn someone's daily running route; nothing broken, behavior deviates|../patterns/safety-and-abuse-resistance.md|
|Ejector-seat action|Drastic, irreversible control → keep it away from positive actions|../patterns/friction-undo-and-confirmation.md|
|Empathy map, journey map, persona|Research tools closing designer-user mental-model gap; journey maps also expose experience's emotional peaks|../laws/mental-model.md|
|Endowed progress|Head start toward goal raises motivation to complete it|../laws/goal-gradient-effect.md|
|Epistemic discomfort|Unease when belief experienced as knowledge gets challenged; abrupt contradiction w/o context hardens it|../evidence/filter-bubbles-and-polarization.md|
|Ethical hierarchy of needs|Rights → effort → experience; delight built on rights violations = not ethical design|[Principles index](../principles/index.md)|
|Experiencing self / remembering self|Moment-by-moment experience vs its stored story; stored story drives future choices|../laws/peak-end-rule.md|
|External memory|On-screen/physical aid holding task information for user; e.g. comparison table, cart, summary + notes|../laws/working-memory.md|
|Extreme-content testing|Stress-testing layouts w/ worst real/invented content, not ideal placeholder content|—|
|Eye-tracking|Recording where + how long people look, to check if key content sits on their scan path; useful for studying banner blindness + selective attention|../laws/selective-attention.md|
|False floor|Strong horizontal break making users think page has ended|—|
|Feature creep (featuritis)|Marginal features pile up until core task suffers|—|
|Feedback|Immediate, visible signal of whether action succeeded/failed; set out in this sense 1988|../patterns/feedback-loading-and-performance.md|
|Feedforward|Showing what action will do before user takes it|—|
|Figure-ground|Most basic scene segmentation: one region seen as object in front, rest as background continuing behind it; edge shared by both regions belongs to figure; described 1915|../laws/gestalt-principles-overview.md|
|Filter bubble vs echo chamber|Both = isolation from contrary views. Filter bubble: from algorithmic ranking. Echo chamber: from self-selected communities|../evidence/filter-bubbles-and-polarization.md|
|Fitts's Law|Target distance + size set time to hit it|../laws/fittss-law.md|
|Flicker paradigm|Scene alternates w/ altered version of itself, blank screen between; lab analogue of page loads + transitions|—|
|Flow|Complete absorption; enjoyment + concentration charged w/ energy; needs challenge matching skill. Autotelic = rewarding in itself. Hyperfocus = flow-like absorption trapping person to own detriment|../laws/flow.md|
|Fluency heuristic|Smoothly processed information judged more valuable or more correct, regardless of accuracy|—|
|Framing effect|Equivalent descriptions of one thing (gain vs loss, success vs failure) → different choices|../laws/cognitive-bias.md|
|Friction|Extra time/effort spent because of how product gets built. Frictionless design = industry's long-standing drive to strip it out. Deliberate, useful kind = positive friction (N-P)|glossary-n-p.md|
|Friction-value curve|Bell curve: too little friction strips ownership + control; too much destroys value|[Principles index](../principles/index.md)|
|Futures wheel|Diagram: change ringed by first-, second- + third-order consequences; each scored for likelihood + impact|../methods/futures-wheel.md (how to run it)|
