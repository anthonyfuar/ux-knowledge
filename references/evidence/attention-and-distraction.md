# Attention and distraction

## Use when
- Scope: research, statistics, cases + expert arguments on interruption cost, phone checking, notification load, calm technology + revenue funded by attention.
- Open when designing/reviewing/arguing about notifications, alerts, ambient pull / anything else interrupting.
- Backs principles: ../principles/respectful.md, ../principles/finite.md, ../principles/empowering.md.
- Definition used throughout: distraction = misalignment between person's goals + product's goals. → Define product success by person's own goals.

## 4. Calm technology + the periphery
- Mechanism: attention's periphery can track far more than its center; moving something from periphery back to center gives person control.
- Origin: calm technology set out in essays from 1995 + 1996.
- Case: 1990s installation hung string in hallway; string moved w/ network traffic = peripheral display w/ no screen + no software.
- → Put status in periphery (tone, light, subtle badge); let people promote it to center when they want.

|Finding|Study (year, kind, sample)|Strength + caveat|Design consequence|
|---|---|---|---|
|Ubiquitous computing expected to overtake personal computing around 2005-2020|industry projection in mid-1990s essay|projection, not measurement; approximate window|Every device taps one fixed attention pool → audit total attention load, not each feature alone|
|Mid-1990s home held ~40 microprocessors|—|approximate count|Every device taps one fixed attention pool → audit total attention load, not each feature alone|
|Calm ranks among century's central design challenges|argued by mid-1990s essay's authors|argument|Every device taps one fixed attention pool → audit total attention load, not each feature alone|

## 5. Interruption guidance from demanding settings
- Source: 2018 inclusive-design toolkit from large software company; guidance from interviews w/ chefs, ER doctors, pilots, cognitive psychologists, non-native speakers + disabled people.
- Its 5 interruption considerations: match urgency to medium · adapt to behavior · adapt to context · enable adaptation · cut mental cost.
- If choosing how message arrives → let urgency decide modality.
- If message low-priority → never stack sound + vibration + screen on it.
