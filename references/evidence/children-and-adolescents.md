# Children and adolescents

## Use when
- Designing / reviewing anything children / teenagers may use.
- Backing age-appropriate defaults w/ evidence.
- Covers minors + short-form video, persuasive mechanics, lost sleep, data collection; each row → design consequence.
- Backs principles: Inclusive, Resilient, Finite.
- Before quoting any figure on minors → check traps + limits in citation-caveats.md.

## Short-form video: mood, memory, attention

|Finding|Study (year, kind, sample)|Strength + caveat|Design consequence|
|---|---|---|---|
|TikTok use disorder (problematic short-video use) associated w/ adolescent depression, anxiety + stress|2021 peer-reviewed study, 3,036 Chinese senior-high students from 1 school|Associated; cross-sectional, authors warn against causal claims; sample not representative|Attention + mood harms = constraints on short-form feed design; build in breaks + limits|
|Same disorder associated w/ lower forward + backward digit span (memory measure)|Same 2021 study|Associated; same caveats|Attention + mood harms = constraints; build in breaks + limits|
|Depression + anxiety partly mediated link between disorder + memory effect|Same 2021 study|Partly; same caveats|—|
|Females scored higher on disorder; males showed more distress|Same 2021 study|Same caveats|—|
|Tolerance for slow-arriving rewards drops → people abandon longer / effortful tasks|Rapid-reward-habit commentary reported w/ 2021 study|Not measured in 2021 study|—|
|Rapid-reward feed = not neutral neighbour to slow content: placed beside long-form material, trains people away from it|—|Mechanism|—|
|TikTok use over long periods linked w/ three harms: steep attention-span drop; struggle staying w/ slow-payoff pursuits; raised stress, anxiety + depression|2024 essay|Linked; essay says effects appear w/ as little as 20 minutes on app, figure unverified|Session length = risk variable for minors on short-form video; build feed breaks in well before twenty-minute mark|
|Feed content urging, glamorizing / normalizing suicide can let TikTok feed worsen person's existing mental-health problems|2024 essay|Can; essay claim|See recommendation drift below|
|Short-form video apps engage via short thrill bursts; bursts can become addictive|2023 study of college students; 2019 study; 2024 coverage|Can|—|
|Collective attention span apparently narrowing|Same 2023, 2019 + 2024 sources|Appears|—|

Term: TikTok brain = nickname for two-sided pattern: impatience when rewards come late + struggle to stay w/ slow-payoff pursuits.

## Developing brains and persuasive mechanics

|Finding|Study (year, kind, sample)|Strength + caveat|Design consequence|
|---|---|---|---|
|Prefrontal cortex (governs directed attention) matures at ~age 25|—|Approximate age|Apply stricter defaults for users under 18; do not assume adult self-regulation in young users|
|Persuasive design reaches children via faster route to drives they already have|Child psychologist's 2018 essay|Mechanism|Ask what mechanic displaces, not only how long it runs|

## Age-aware defaults already shipped

|Finding|Study (year, kind, sample)|Strength + caveat|Design consequence|
|---|---|---|---|

|Major video service sets autoplay off + default break + bedtime reminders for under-18s|Platform wellbeing catalog|↑|Copy shipped default set|

Age-aware protective defaults = industry baseline, not differentiator.

## Data collection and secondary use

|Finding|Study (year, kind, sample)|Strength + caveat|Design consequence|
|---|---|---|---|
|>250 game apps, some made for children, included software listening for TV ads even when app not in use → such listening = surveillance reaching vulnerable users w/o meaningful consent|2017 newspaper investigation|Documented case|Minimize data collection + default sharing to private in any product minors may use|
|Secondary data use in sensitive contexts breaks trust even when person consented to initial collection|—|Mechanism|Bind data to its collection purpose; any new use of existing data → off by default + announced before it starts|

Hypothetical examples:
- Hypothetical: family transit-card app shows each child rider's trip history to every other card holder in school travel group unless guardian changes setting → breaks private-by-default for minors.
- Hypothetical: debt-advice service passes clients' financial-hardship + stress notes to partner lenders by default → secondary use in sensitive context; breaks trust though clients consented to original collection.
