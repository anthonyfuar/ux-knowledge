# Engagement vs empowerment metrics

## Use when
- Choosing/auditing dashboard numbers → separate capture metrics from benefit metrics.

## Key terms
- Engagement metric = attention captured.
- Empowerment metric = capability + agency grown in person.

## Steps
1. List every dashboard number.
2. Ask of each: would person recognize it as own goal?
3. Sort each into capture (engagement) or benefit (empowerment); each capture number → find swap-table counterpart.
4. Standard: attention-competing products take person where they meant to go.

## Swap table
|Engagement metric (capture)|Empowerment counterpart (benefit)|
|---|---|
|Time on site, sessions per day, pages per visit|Task completed; overall time saved; people reporting quickly finding something satisfying|
|Habit-loop-driven retention|People returning because product helped; person would recommend it to loved one|
|Notifications opened|Notifications people chose to keep on|
|Shares, likes, invites generated|Meaningful interactions + relationships improved, as self-reported|
|Add-ons accepted by default|Choices actively made + later endorsed|

## Hypothetical example
Hypothetical: lift stopping at floors nobody pressed so riders pass lobby advert → riders would report it broken. Recipe app counting browsing minutes while person wanted dinner decided fails same test; "meals planned that the person cooked" passes.

## Pitfalls
- Reading high engagement number as benefit → run own-goal question first.
- Counting accepted defaults as choices → count only choices actively made + later endorsed.
