# Lightening mental effort

## Use when
- Screen/flow presents excess options, lacks clarity or demands excess thought.
- Designing/reviewing screen or flow for less processing adding nothing to understanding (cutting extraneous cognitive load).

## Key terms
- Intrinsic load = effort of taking in new information + holding goal in mind.
- Extraneous load = effort buying no understanding.
- Target extraneous load, not intrinsic.

## Steps
1. **Accept floor**: some cognitive load unavoidable (intrinsic).
2. **Audit three causes of extraneous load**, by origin: what screen offers (excess options, missing clarity) · what it asks of person (excess thought).

Steps 3-6: seven load reducers, grouped by what they act on (as in ../laws/cognitive-load.md).

3. **What users already recognize**:
   - swap custom patterns for familiar ones where they fit
   - label icons unless universally understood
4. **Option set**:
   - keep option sets whole: never move part of option set into out-of-sight group; options belonging together stay together
   - limit options where it counts most: drop-downs, forms, navigation. No moment carries more than a few options. Myth: satisfaction grows w/ choice amount.
5. **What screen shows**:
   - make text readable, not merely legible; typography suits content + does not call attention to itself
   - user-goal test per element: contributes nothing to user's goal → cut (e.g. surplus layouts, ornament, imagery, color). Stop cutting when clarity would suffer; clarity sets limit.
6. **Work left to user**: take decisions, memory work + reading off user:
   - consider anticipatory design (system predicts + decides for user)
   - reuse data user already gave
   - use defaults staying open to change
7. **Re-check**: goal completion more probable as effort of working out what to do shrinks.

## Hypothetical example
Hypothetical: clinic appointment-booking screen shows decorative photos, unlabelled calendar icon, drop-down of every clinician. Cut photos (no goal served), label icon, pre-fill patient's usual clinic from earlier visits as changeable default, keep all morning slots in one visible group instead of hiding some behind "more times".

## Pitfalls
- Trying to remove intrinsic load → target extraneous only.
- Cutting past clarity → stop when clarity would suffer.
- Hiding part of related option set to look simpler → keep together options belonging together.
- Anticipatory decisions/defaults people cannot change → defaults stay open to change (humane bound in Related).
