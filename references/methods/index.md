# Methods index

## Use when
- Choosing method to run per design stage. Every method file by group w/ when to use it.

## Stage rules
- Humane-design methods (Foresight, Metrics, Arguing + team practice groups) = instruments for seven humane principles: Respectful, Finite, Empowering, Intentional, Inclusive, Resilient, Transparent.
- Use them in discovery, design review, launch gating + post-launch monitoring.
- Foresight → run in discovery + planning, while decisions cheap to change.
- Retrospectives find friction after shipping; foresight methods find harm before shipping.
- End each foresight exercise by revising plan; otherwise = theatre.
