# Four quadrants of design responsibility

## Use when
- Checking what significant design decision answers for beyond single user.

## The grid
Rows = what gets built. Columns = whom it serves/affects.

|Built ↓ / Affects →|One person|Community|Society|
|---|---|---|---|
|Pixel|Familiar craft territory|Cultural variation in visual meaning|Symbols at scale|
|Product|Human-centred usability|Norms, moderation, group dynamics|Market + legal externalities|
|Ecosystem|Data trails + lock-in|Network effects|Infrastructure-level effects on housing, traffic, public space, elections|

## Steps
1. Know comfort zone: teams comfortable in top-left cell (pixel, one person).
2. Walk every significant decision across grid toward bottom-right (ecosystem, society).
3. While walking, ask: what changes as constraints, interdependencies + cultural variation grow?
4. Far quadrants → bring in sociology, public health, economics.

## Hypothetical example
Hypothetical: grocery-delivery app adds "nearest store" sort.
- Pixel / one person: sort control clear?
- Pixel / community: distance icon reads same across communities served?
- Product / community: shoppers in some neighbourhoods always see fewer stores?
- Ecosystem / society: if every household sorts by nearest, what happens to delivery traffic + shops barely outside radius?

## Output
- For each significant decision: cells touched, what changes there, outside disciplines consulted.

## Pitfalls
- Stopping in top-left cell because familiar → walk to bottom-right.
- Judging society-level cells w/ design expertise alone → bring in sociology, public health, economics.
