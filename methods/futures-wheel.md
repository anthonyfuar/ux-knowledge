# Futures wheel

## Use when
- Map proposed change's consequences in concentric rings → find items both likely + strongly negative → each gets mitigation + early-warning signal.
- Origin: consequence-mapping method from early 1970s.

## Who to invite
- Cross-functional partners, domain experts, people w/ first-hand experience of abuse / marginalization.
- Why: varied perspectives surface hidden consequence rings.

## Steps
1. Proposed change at board centre.
2. **Ring 1:** change's direct consequences, positive + negative.
3. **Ring 2:** what each ring-1 item causes in turn.
4. **Ring 3:** repeat.
5. **Score every item** for likelihood + impact.
6. **Flag** items both likely + strongly negative → each gets mitigation + early-warning signal.
7. **Store wheel** w/ project record; revisit at milestones.

## Decision rules
- If wheel stops at ring 1 → keep going; harms usually live in outer rings.
- If only one discipline in room → invite groups above; hidden rings stay hidden otherwise.
- If item likely + strongly negative but no mitigation / no early-warning signal → step 6 not finished.
- If wheel made once + filed → revisit at each milestone.

## Output
- Wheel w/ three consequence rings, each item scored for likelihood + impact.
- Flag list: likely + strongly negative items, each w/ mitigation + early-warning signal.
- Stored w/ project record; revisited at milestones.

## Pitfalls
|Symptom|Likely cause|Fix|
|---|---|---|
|Map shows few harms|stopped at ring 1|push to rings 2 + 3, where harms usually live|
|No surprises on board|homogeneous group|add domain experts + people w/ lived experience of abuse / marginalization|
|Risks named, nothing changes|no mitigation / signal assigned|complete step 6|

## Hypothetical example
- Hypothetical: school district plans grade-change alerts to parents as soon as teachers enter grades. Ring 1: parents informed sooner (positive); students lose chance to share news themselves (negative). Ring 2: some students hide failing work from teachers to delay alerts. Ring 3: in homes where bad grade → punishment, alert hits student's riskiest setting first. Flagged (likely + strongly negative) → mitigation: student sees change first, w/ delay; early-warning signal: drop in submitted work after alerts start.
