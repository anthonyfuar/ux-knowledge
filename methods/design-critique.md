# Design critique

## Use when
- Setting up / running recurring design-team critique of rough work, structured to keep goals apart from solutions.
- Procedure = 6 steps.

## Which meeting is this?
|Meeting|Description|
|---|---|
|Generative|divergent, held early|
|Evaluative|purpose = approval|
|Design critique|recurring; critiques rough work; goals kept apart from solutions|

If session's aim = approval / open idea generation → not design critique; run matching meeting instead.

## Steps
1. **Attendance = design team only**, incl. its researchers + writers → psychological safety. Size: ~4 minimum for good discussion flow; 15 or more tends to derail.
2. **Rotating facilitator** balancing loud + quiet voices; facilitator's views carry no extra weight.
3. **Weekly, often one hour.** Fill e.g. w/ three bookable 20-minute presenter slots.
4. **Presenter frames first:** work's stage + feedback wanted → then shows rough work. Feedback usually at end of presentation.
5. **Attendees write notes / sketch during presentation** → hand to presenter.
6. **Keep explorations detailed enough to convey idea, no more.**

## Decision rules
- If fewer than ~4 people → discussion flow suffers; add design-team members.
- If 15 or more → tends to derail; keep group smaller.
- If remote → arrange good video + extra facilitation.
- If feedback drifts off topic → suspect presenter's framing (step 4).
- If explorations hold more detail than idea needs → cut back; compare several distinct models over polishing first one.

## Pitfalls
|Symptom|Likely cause|Fix|
|---|---|---|
|Off-topic feedback|presenter framed work poorly (often)|state stage + feedback wanted up front|
|Loud voices dominate, quiet ones unheard|no facilitator balancing voices|rotating facilitator balancing them|
|Facilitator's taste decides|facilitator's view treated as weightier|give it no extra weight|
|Most time sunk into polishing first idea|teams slip into it easily|minimal detail; bring several distinct models|
|Low psychological safety|attendance beyond design team|keep to design team|

## Citation caution
- 80% of design time spent polishing first idea: figure from 2015 practitioner illustration = hypothetical, not measured. Do not quote as data.

## Hypothetical example
- Hypothetical: designer on grocery-delivery team opens slot w/: "early exploration, several directions for the substitution flow; I want reactions on which model fits shoppers, not on visuals." Attendees sketch alternatives on cards, hand them over; feedback held until end stays on models.
