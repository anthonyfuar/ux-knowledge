# Calm-technology scorecard

## Use when
- Scoring product on attention, notifications, privacy, well-being + failure states.
- 5 categories: user experience · notifications + indicators · privacy + security · digital well-being (time well spent) · support + fail states.
- Companion questions (below) go beside category scores.

## Scoring steps
1. Each category starts at 100 points.
2. Per positive item (+) present → add points; per negative item (−) present → subtract.
3. Clamp each category score to 0–100.
4. Clamped score → letter grade.

## Weights
- Item weights = indicative only → adjust to scored product.
- If reweighting → keep opt-out data practices among largest penalties.
- If reweighting → keep alerts on by default among largest penalties.

## Origin
- Adapted from popularized product self-assessment approach, built on calm-technology idea.
- Term calm technology coined in 1990s.

## Category 1: user experience
|Item present|Effect|
|---|---|
|Physical controls / warm-coloured (orange / green) indicators|+|
|Frequently used functions within 1 click|+|
|Text size person can adjust|+|
|Captions|+|
|Colour-blindness compensation|+|
|Only minimal information shown at all times|+|
|Bright blue LED always on|−|
|Tiny targets|−|
|Common functions buried 3 clicks deep|−|
|Forced updates before person can use product|−|
|Every metric shown constantly|−|

## Category 2: notifications + indicators
|Item present|Effect|
|---|---|
|Notifications off by default, except crucial few|+|
|Person asked at sign-up how they want notifications|+|
|Distinct alert classes by importance|+|
|Global mute|+|
|One-click night / safe mode|+|
|Scheduled quiet hours|+|
|Soft transitions, e.g. fades + ramps|+|
|All notifications on at sign-up|−|
|One undifferentiated channel for all alerts|−|
|Alerts person cannot silence|−|
|Repeated prompts to enable notifications|−|
|Abrupt alerts at full brightness|−|

## Category 3: privacy + security
|Item present|Effect|
|---|---|
|Plain-language terms beside legal text|+|
|Anonymous / no-account mode|+|
|Data collection shown w/ when, where + why|+|
|Data deletion + export any time|+|
|Third-party sharing = opt-in|+|
|Two-factor authentication supported|+|
|No face recognition w/o person's permission|+|
|Data sold|−|
|Data sharing opt-out, not opt-in|−|
|Forced social login for appliance|−|
|No data export path if service shuts down|−|
|Credentials stored insecurely|−|

## Category 4: digital well-being (time well spent)
|Item present|Effect|
|---|---|
|Elapsed time visible|+|
|Pause + break controls|+|
|One-click replies not dictating what person says|+|
|No engagement hooks|+|
|Rating prompts right after use|−|
|Banners pushing app install|−|
|Forced sign-in before person can view content|−|
|Infinite feed w/ no sense of time passing|−|

## Category 5: support + fail states
|Item present|Effect|
|---|---|
|Offline mode keeping saved state|+|
|Low-speed mode|+|
|Failsafe baseline of function|+|
|Several support channels, incl. voice|+|
|Chatbot hands off to human + passes details|+|
|Tested in noise, glare, motion + low battery|+|
|Device = brick when offline|−|
|Bot loop w/ no exit|−|
|Tested only in quiet, well-lit, fully connected room|−|

## Companion questions
1. Best use of person's attention?
2. Informs w/o overburdening?
3. Degrades gracefully?
4. Tested under sub-optimal conditions?
5. Data handling + terms understandable?
6. Can people sign up anonymously?
