# Addiction and variable rewards

## Use when
- Scope: research, statistics, insider accounts + expert arguments on compulsion loops, variable rewards, engineered engagement + time lost to products.
- Open when designing/reviewing/arguing about feeds, autoplay, streaks, like counts, reward timing or any other mechanic possibly driving compulsive use.
- Backs principles: ../principles/finite.md, ../principles/intentional.md, ../principles/respectful.md.

## 1. Variable rewards
|Finding|Study (year, kind, sample)|Strength + caveat|Design consequence|
|---|---|---|---|
|In US, slot machines earn > baseball, movies + theme parks combined|anthropological book on machine-gambling design; figure cited in 2016 essay|book-length study; figure via secondary citation (2016 essay)|Replace unpredictable w/ predictable, scheduled reward delivery|
|Problem involvement develops 3-4x faster w/ slot machines than w/ other gambling forms|same book|book-length study|↑|

- Mechanism: slot-machine pull = intermittent variable reward.
- Slot machines' intermittent variable reward now appears in product mechanics, e.g. pull-to-refresh, swipes, badges.

## 2. Bottomless feeds + missing stopping cues
|Finding|Study (year, kind, sample)|Strength + caveat|Design consequence|
|---|---|---|---|
|People eating from self-refilling soup bowl ate 73% more calories|food-psychology experiment|eating study; used as template for how bottomless feeds + autoplay work|Restore feed stopping cues: pagination, "all caught up" message, deliberate load-more control|
|Same eaters underestimated intake by ~140 calories|same experiment|figure approximate|Restore feed stopping cues: pagination, "all caught up" message, deliberate load-more control|
|Infinite scroll invented 2006; inventor later voiced regret|regret: 2018 investigative broadcast + other public statements|regret = inventor's own account|Continuous loading only for aimless browsing of homogeneous content; else load-more control|
|Per inventor, infinite scroll removes pause brain needs to catch up w/ its impulses|inventor's public statements|inventor's own account|Continuous loading only for aimless browsing of homogeneous content; else load-more control|
|Inventor blamed funding + stock-price pressure (pushes companies toward time-spent metrics) for how mechanic got used|↑|↑|Continuous loading only for aimless browsing of homogeneous content; else load-more control|

- Mechanism (2016 expert essay on attention-capturing design): by design, feed keeps topping itself up + never gives person cue to leave, reconsider or stop.

## 3. Personalized feeds + reward circuitry
- TikTok holds viewers as if hypnotized; means = brief clips picked per person, served in never-ending feed.
- TikTok's effectiveness on brain reward circuitry = explanation most often given for its fast growth (2024 essay critical of algorithm-tailored feeds).
- Recommender tuned to stretch sessions runs on what TikTok's interface records: every viewer action; interface itself = sensor.
- TikTok's loop: targeting sharpens → sessions lengthen; each session sharpens targeting further. Loop yields more ad views + more data.
- Feed winning by capturing reward system aims at neither worth to person nor genuine bonds w/ others; its goal = keeping people there.
- Ranked feed built to hold people → give person on receiving end controls to direct it.
