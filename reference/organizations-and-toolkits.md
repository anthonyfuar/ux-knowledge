# Organizations and toolkits

Groups, toolkits, frameworks, manifestos + movements on humane technology: description + offer of each; then podcasts + newsletters. Works described, not titled.

## Use when
- Team needs outside toolkit, standard or community.
- Identifying group, manifesto, movement, podcast or newsletter.
- Someone asks what to listen/subscribe to.
- No outside toolkit wanted → run ../checklists/humane-design-audit.md instead.

|Resource|What it is + offers|
|---|---|

## Ethical-design frameworks + standards
|Framework|What it holds|
|---|---|
|Ind.ie pyramid|Pyramid manifesto by independent-technology social enterprise; ranks ethical-design layers: human rights at base → human effort → human experience. Human-rights base = decentralized, private, open, interoperable, accessible, secure, sustainable|
|Value sensitive design|Makes values explicit in design process; techniques range from value heuristics to mapping value tensions (e.g. security vs privacy). Limit: criticised as descriptive, not prescriptive, about what values to hold|
|Privacy by design|Long-standing framework for handling sensitive data; still reference point for privacy fundamentals|
|Santa Clara Principles|Transparency + accountability standards for content moderation|

## Inclusion + accessibility
|Resource|What it is + offers|
|---|---|
|Microsoft inclusive-design toolkit|Persona spectrum, guidebooks + workshop tools; adds 5 interruption considerations influenced by calm technology|
|University of Cambridge inclusive-design toolkit|Engineering-design methods + performance indicators for assessing exclusion|
|Project Lima|Workbook template for spotting exclusions + building persona spectrums w/ team in one session|
|WCAG (W3C)|Requires perceivable, operable, understandable + robust content; conformance levels A, AA, AAA|
|Seven inclusive design principles (one published set)|Give everyone comparable experience; account for person's situation; stay consistent; leave people in control; offer choice of ways through; put content first; add value w/ each feature. Checklist pitched between abstract inclusion commitments + per-component accessibility rules|
|Project Inkblot|Framework for diversity in design built on core questions (below)|

- Case: UK bank's accessibility team published 7 diverse personas to replace average user.
- Exclusive design method, steps: 1. study situation → 2. ignore conventions → 3. prioritize identity → 4. add nonsense.
- Project Inkblot questions: Worst case + on whom does it fall? Who at the table? Who excluded? Engagement equitable? Ongoing review?

## Emotion, mental health + presence
|Resource|What it is + offers|
|---|---|
|One design studio's lookbook|Emotion-centered design methods: object interviews, inner-circle mapping, norm distortion, reflective templates|
