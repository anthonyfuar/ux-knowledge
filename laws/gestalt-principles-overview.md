# Gestalt Grouping Principles (overview)

## In one line
Common ground of five grouping (perception) laws: origin, mechanism of every cue, how cues combine + compete, limits of every law. Open before citing, ranking or combining grouping cues, or when layout's cues conflict.

- Five laws: common-region.md, [Prägnanz](pragnanz.md), proximity.md, similarity.md, uniform-connectedness.md.
- Umbrella idea = Prägnanz: scattered elements seen as complete things in orderly arrangements; no instruction needed.

## Cue families
No definitive list of grouping principles exists; usual sorting: five families (alphabetical: Closure, Connectedness, Continuity, Proximity, Similarity); classic literature adds symmetry, common fate, parallelism, convexity + area.

|Cue|What it does|Status / note|
|---|---|---|
|Closure|—|usual family|
|Connectedness|Uniform Connectedness = connector or continuous link|usual family; stated 1994, first called element connectedness → uniform-connectedness.md|
|Continuity|(good continuation in 1923 list)|usual family|
|Proximity|groups by spacing|usual family; 1923 formulation → proximity.md|
|Similarity|groups by likeness|usual family; 1923 formulation → similarity.md|
|Common region|groups by shared boundary or fill (enclosure)|formally stated 1992 → common-region.md|
|Symmetry|mirrored elements bind around their center|can beat proximity; rests on demonstrations only|
|Common fate|shared motion groups elements|real motion groups more strongly than implied (arrows, gaze direction)|
|Parallelism|parallel line-like shapes seen as one set|—|
|Convexity + area|convex + smaller regions seen as figure|—|

## Decision rules
- If laying out grouped content → make spacing, color + enclosure all favor same partition, before any styling, w/ [grouping-first pass](../methods/gestalt-layout-pass.md).
- If grouping cues conflict → do not predict winner from ranking; validate important groupings w/ users.
- If someone cites fixed strongest cue → reject; winner depends on each cue's magnitude → make cues agree + test.
- If element must read as figure (in front) → smaller, convex, symmetric or enclosed regions tend to read as figure.
- If control/icon must stand out from background → familiar shapes win figure status → use recognizable silhouettes.
- If control sits in busy linework or styled like surroundings → can vanish; make it dissimilar from surroundings.
- If items should read as one moving set → real shared motion groups more strongly than implied (arrows, gaze direction).
- If choosing layouts → ones w/ real-object cues (occlusion, shared motion, closed contours) parse easiest.
- If grouping by box vs line → choose on purpose: Common Region = enclosure by boundary or fill; Uniform Connectedness = connector or continuous link.
- Every element judged within surrounding layout, never alone.

## Why it works
1. One partition wins: of astronomically many ways scene could split, vision spontaneously settles on one or a handful; others seen only w/ effort, only locally + only briefly.
2. Groups pull attention: attention does not produce grouping; groups attract attention.
3. Whole first: whole perceived first, assigns roles to parts → element always judged within surrounding layout.
4. Figure-ground segmentation: one region seen as figure in front; figure owns edge shared w/ background.
5. Camouflage: embedded shape vanishes because regrouped w/ surroundings (hidden-figure effect).
6. Why cues exist, two views:
   - Innate: rule-bound sorting of sensory input, present from birth → grouping laws; Gestalt school's own justification.
   - Learned (heuristic view, 1975): laws = heuristics learned from physical objects' regularities, not innate as Gestaltists held. Regularities: objects in front of backgrounds; uniform texture; parts near each other + moving together; closed continuous contours.
7. 1923 method behind grouping principles: vary one factor (e.g. spacing) while holding another (e.g. likeness) constant, pit two against each other, compare strength.

|1929, 1935, 1936|grouping principles extended; 1936 work translated 2006|
|1938|translated excerpts of 1923 statement|
|by mid-20th century|Gestalt theory declined because it described w/o explaining; later quantitative work revived it|
|1975|heuristic (learned) view of laws|
|1992|common region formally stated|
|1994|uniform connectedness formally stated, first called element connectedness|

## Misreadings and limits
- Wrong: whole = more than sum of its parts. → Right: whole differs from sum of its parts (1935 extension corrected slogan).
- Wrong: "connectedness is strongest", "common region is strongest", "connectedness always wins". → Right: fixed-strength rankings in design writing repeat demonstrations, not measured laws; winner depends on each cue's magnitude → make cues agree + test.
- Wrong: Closure comes from 1994 paper introducing uniform connectedness. → Right: that paper concerns connectedness, not closure.
- Wrong: Common Region + Uniform Connectedness = one rule, "draw a box around it" (practitioners often merge them). → Right: keep distinct: enclosure by boundary or fill vs connector or continuous link.
- Wrong: complete list of grouping principles exists. → Right: no definitive list exists.
- Wrong: Gestalt laws explain grouping. → Right: descriptive, not explanatory; "good" or "simple" form never precisely defined.
- Limit: every grouping law carries implicit "all else being equal".
- Limit: when grouping cues conflict, one cue usually wins or percept turns unstable; no worked-out theory predicts outcome.

## Symptoms → fixes
|Symptom|Likely cause|Fix|
|---|---|---|
|Control/icon lost in surroundings|regrouped w/ busy linework or styled like surround (camouflage)|make it dissimilar from surroundings; give recognizable silhouette|
|Groups read other than intended, or layout flips between readings|cues conflict → one wins or percept unstable|make spacing, color + enclosure favor same partition; validate important groupings w/ users|
|Team argues which cue "always wins"|fixed-strength ranking taken from demonstrations|compare cues' actual magnitudes; make them agree; test|
|Box drawn where link meant, or reverse|Common Region merged w/ Uniform Connectedness|choose enclosure vs connector on purpose|
