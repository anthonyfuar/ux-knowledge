# Law of Uniform Connectedness

## In one line
Visible links drive perceived relatedness: items joined by drawn link read as more closely related than items w/o one. Matters for: borders on priority items, connector lines in steppers + diagrams, linking related controls.
- Type: effect/principle. Aliases: uniform connectedness; connectedness, one of five Gestalt families. Theme: Perception.
- Core rule: lines, arrows, frames + shared color link related functions; border also raises priority → reserve it.

## Applies when / does not apply when
|Applies when|Does not apply / cite something else when|
|---|---|
|Real relationship exists between elements|No real relationship: use no connector|
|Cue = connector or continuous link (line, arrow, frame, shape, color)|Cue = enclosure by boundary or fill → Common Region; keep both distinct|
|Connector competes w/ proximity or similarity: can bind against both|Fixed cue ranking assumed: none exists; rankings come from demonstrations + winner depends on cue magnitude|

## Decision rules
- Same-purpose functions → make kinship visible: joining stroke, common hue, or enclosing outline (box or any shape).
- Connector lines + arrows = cue in own right: one mark between elements ties them, no other cue needed.
- Name link's job before drawing it: situate items in wider setting, or stress that look-alike items belong to one kind.
- If proximity cannot bind elements → line, arrow or shared frame.
- If linking control to content it acts on, or label to distant target → lightest working connector.
- Borders = emphasis budget → spend only on content worth elevating: border makes enclosed content look more important, beyond binding it into one group + setting it apart from neighbours.
- If cues could disagree → make them agree + test.

## Why it works
Mechanism:
- Visible connector = strong cue: connected items read as one unit, more related than unconnected ones + set apart from surroundings.
- Connector binds elements even against proximity + similarity; need not touch them.

Origin:
- Named 1994, first as "element connectedness"; belongs to Gestalt connectedness family.
- Other perception + grouping laws come from Gestalt psychologists: Prägnanz 1910; Proximity + Similarity formalized 1923; Common Region 1992; Uniform Connectedness 1994.
- Proximity + Similarity: no person or study beyond 1923 grouping formalization → attribute to Gestalt psychologists collectively.

## Misreadings and limits
- Wrong: ranking grouping cues by fixed strength ("connectedness always wins") (Gestalt laws) → Right: rankings come from demonstrations; winner depends on cue magnitude → make cues agree + test.
- Wrong: merging Common Region + Uniform Connectedness as "draw a box around it" (practitioners often do) → Right: enclosure by boundary/fill vs connector or continuous link.
- Wrong: crediting Closure to 1994 connectedness paper → Right: this paper concerns connectedness.
- Wrong: citing grouping laws as processing model → Right: innate (Gestalt view) vs learned from real-object statistics (1975 view) = contested → cite as reliable descriptive tendencies.
- Wrong: citing Gestalt therapy as perceptual evidence → Right: separate field; argued to have no substantive relation to Gestalt perception research.

## Symptoms → fixes
|Symptom|Likely cause|Fix|
|---|---|---|
|Ordinary content looks more important than warranted|Border or frame raising priority it does not deserve|Remove border; reserve borders for content deserving emphasis|
|Unrelated items read as linked|Connector or shared color where no relationship exists|Connectors only where real relationship exists|
|Control or label seems detached from its target|Proximity alone cannot bind them|Lightest working connector: line, arrow or shared frame|

## Hypothetical examples
- Hypothetical (border = priority + one unit): bank-statement view frames "payment due" summary in bordered box → gains priority, stands apart from ordinary transaction rows + reads as one unit.
- Hypothetical (link to a distant target): hiking-map callout pointer runs from label to its trailhead pin, tying both across empty terrain.
- Hypothetical (trigger joined to what it opens): hotel-booking page's selected date field flows w/o gap or dividing line into calendar panel it opened → field + calendar read as one connected unit.
- Hypothetical (frames turn a crowded panel into chunks): smart-oven control panel frames its buttons into a few clusters (cooking modes, timer, settings) → panel no longer overwhelms.
- Hypothetical (consistent markers tie a list): travel itinerary marks every stop of a day w/ same numbered marker style.
